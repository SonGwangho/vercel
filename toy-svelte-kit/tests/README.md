# Lounge 회귀 검증

`toy-svelte-kit`에서 실행한다.

```sh
npm run test:lounge
npm run check
npm run build
npm run test:lounge:browser
```

- `test:lounge`: 서버 간 알림 유실, 담당 서버 교체, 체크포인트 저장 중 명령 경합, 중복 입장·행동, 응답 없는 연결, 누락된 상태 변경, 취소 및 재입장을 검증한다. Neon의 세션 잠금·알림 전달을 모사하며 실제 데이터베이스에 접속하지 않는다.
- `test:lounge:browser`: 빌드 결과를 로컬에서 실행하고 실제 WebSocket과 새 임시 Chrome/Edge 프로필을 사용한다. 입장 화면의 1440/768/390px, 150ms 지연 중 이동 요청 병합, 연결 강제 종료 후 복구, WebGL 컨텍스트 복구, 모바일 다크 테마를 검증한다. 방 저장소는 테스트용 메모리 구현이다. 기존 브라우저 프로필이나 로그인 계정을 사용하지 않는다.
- 브라우저 결과·스크린샷은 `.svelte-kit/lounge-browser/`에 생성된다. 프로젝트에 설치된 Taste Skill의 브라우저 도우미와 시스템 Chrome/Edge가 필요하며, 5273 포트를 사용한다.

타입 검사와 빌드는 같은 `.svelte-kit`을 사용하므로 순서대로 실행한다. 이 검증은 실제 Vercel/Neon 연결이나 실사용 동시 접속 부하를 확인하는 테스트와 구분한다.

운영 방 식별 범위는 커밋별 값에서 환경별 고정 값으로 바뀌었다. 이 변경을 처음 배포할 때 이전 버전에서 접속한 사용자는 재입장이 필요할 수 있다. 이후 배포에서는 같은 범위의 체크포인트와 세션을 재사용한다.
